##  Project Overview
This repository contains the final part of the RaceDay POE. The system is split into two distinct projects:
1.  **`RaceDay.API`**: The backend RESTful API built in Part 2. It handles all data operations, session-based authentication, role-based access control, and integrates with Azure Blob Storage for image uploads.
2.  **`RaceDay.MVC`**: The frontend web application built in Part 3. It acts strictly as a client, consuming the API for all data operations without any direct database access or replicated business logic.
